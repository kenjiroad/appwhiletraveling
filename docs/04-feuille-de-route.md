# Étape 4 — Feuille de route jusqu'au lancement

Chaque étape terminée est notée dans `00-journal.md`.

## Phase 0 — Valider avant de coder (semaine 1–2)

- [ ] Valider le nom (App Store, nom de domaine `.fr`/`.app`, Instagram/TikTok, INPI).
- [ ] Trouver **1 coach partenaire** (muscu, 10k–100k abonnés). Proposition : 30–50 % des revenus de son équipe.
- [ ] Faire 10 mini-interviews de pratiquants en salle : « Comment tu choisis ton programme ? Tu paierais combien ? »
- [ ] Créer une **page d'attente** (liste d'inscription e-mail) et la partager via le coach.
- [ ] Créer les comptes : Apple Developer, Expo, Supabase, RevenueCat.

## Phase 1 — V1 minimale (semaine 3–8)

Écrans de la V1 :

1. **Onboarding quiz** : objectif, niveau, matériel (salle/maison), jours par semaine.
2. **Recommandation de coach** (1 à 3 équipes au début).
3. **Paywall** : essai 7 jours, puis mensuel / annuel.
4. **Accueil « Ma semaine »** : les séances de la semaine.
5. **Lecteur de séance** : exercice par exercice, vidéo en boucle, séries/répétitions, minuteur de repos, saisie des charges.
6. **Fin de séance** : récap + célébration + série (streak).
7. **Chat d'équipe** avec le coach.
8. **Profil** : historique, records, abonnement.

Côté coach (au début, simple) : le coach envoie son programme dans un Google Sheet /
formulaire, et on l'importe dans Supabase. Un vrai outil coach viendra plus tard.

## Phase 2 — Bêta privée (semaine 9–10)

- [ ] TestFlight avec 30–100 personnes de la liste d'attente.
- [ ] Corriger les bugs, mesurer la fin d'onboarding et l'usage.
- [ ] Préparer la fiche App Store : captures, texte, mots-clés, politique de confidentialité, CGU.

## Phase 3 — Lancement France (semaine 11–12)

- [ ] Soumission à Apple (review ~24–48 h).
- [ ] Jour J : le coach annonce sur ses réseaux + 3 vidéos TikTok/Reels par semaine.
- [ ] Suivre chaque jour : installations, essais, abonnés, avis.

## Phase 4 — Après le lancement

- [ ] Tests A/B sur le prix et le paywall (RevenueCat).
- [ ] Ajouter des coachs (une nouvelle équipe = une nouvelle audience).
- [ ] Outil coach dans l'app, version Android, nutrition.
